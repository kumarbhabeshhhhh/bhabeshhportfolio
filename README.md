# Bhabesh Kumar Lenka — Portfolio

A static HTML, CSS and JavaScript portfolio website.

## Deployment structure

Keep these files directly in the root of the GitHub repository:

- `index.html`
- `style.css`
- `script.js`
- `resume.pdf`
- `assets/`

Do not upload the ZIP file itself as the website source, and do not place these files inside another folder.

## Vercel deployment

1. Create or open the GitHub repository.
2. Upload the contents of this folder, not the ZIP file.
3. Confirm that `index.html` is visible at the top level of the repository.
4. Import the repository into Vercel.
5. Framework Preset: Other.
6. Build Command: leave blank.
7. Output Directory: leave blank.
8. Deploy.

This is a static website and does not require a build command.
